# 💜 Vantoryn Desk — 無料 Windows デスクトップウィジェット

**Your Desktop, Your Way.** | [ダウンロード・更新情報](https://github.com/DavidV20230/vantoryn-desk/releases) | [問題を報告](https://github.com/DavidV20230/vantoryn-desk/issues)

Vantoryn Desk は、**Windows 10／11（64 ビット）** 向けの無料デスクトップウィジェットアプリです。必要なツールを選択し、ウィンドウを移動・サイズ変更・コンパクト表示することで、システム情報、ゲームのパフォーマンス、ネットワーク、相場情報、日常の便利な機能をデスクトップに配置できます。

このソフトは、**生成 AI を大幅に活用してコードを作成・修正し、実際に使いながら改善を重ねている個人制作の共有作品**です。便利だと思った機能をほかの方にも気軽に使っていただきたいという目的で公開しており、**料金や寄付は必要ありません**。専門企業が保守する商用製品として提供しているものではありません。現在のバージョンは **Public Preview v6（公開プレビュー版）** です。

## 🧩 カスタマイズとデスクトップ配置

- **ウィジェットを選ぶ：** ツール選択画面で、仕事・ゲーム・日常生活に必要なものだけを選択できます。すべてを表示する必要はありません。
- **好きな場所に移動：** マウスでウィジェットをドラッグして配置します。ドラッグ可能な領域はウィジェットによって異なります。
- **サイズ調整：** 対応ウィジェットの辺や角をドラッグして大きさを変えられます。v6 では描画の重複や画面の欠けを減らす処理を試みていますが、実際の滑らかさは環境と内容によって異なります。
- **コンパクト／折りたたみ表示：** 対応ツールを小さくまとめられます。ゲームパフォーマンスツールには画面端に収めるコンパクトなタブ表示もあります。
- **見た目を調整：** 一部のツールでは透明度、背景、表示方法を変更できます。利用できる項目は各ツールの画面をご確認ください。
- **内容をカスタマイズ：** タスクの追加、集中／休憩時間の設定、株式や指数のウォッチリスト、よく使う Web サイトの登録などが可能な機能があります。
- **言語設定：** 初回起動時は **English** が既定です。**ツール選択画面右上**のドロップダウンで **English／繁體中文／日本語** に切り替えられます。選択した言語はユーザー設定に保存されます。

## ✨ 主な機能

| 種類 | 概要 |
|---|---|
| 🎮 ゲームパフォーマンス | 対応環境で FPS、通信遅延、GPU の一部情報を表示。コンパクト表示や画面端タブに対応 |
| 🖥️ システム監視 | CPU、GPU、VRAM、メモリ、ストレージなど、取得可能なハードウェア情報を表示 |
| 🌐 ネットワーク | 通信状況やネットワークの変動を確認する補助情報 |
| 📈 株式・相場 | ウォッチリストや指数を追加し、対応する価格情報やチャートを確認 |
| ₿ 暗号資産 | 一部銘柄の参考価格や変化を表示。売買機能はありません |
| 🌤️ 天気・ニュース | 利用可能な外部データソースから天気予報やニュースを表示 |
| ✅ タスク・メモ | 自分のタスクやメモを追加・管理 |
| ⏱️ 集中タイマー | 標準的な集中／休憩時間を使うほか、時間を自由に変更可能 |
| 🕒 時計・カレンダー・通知 | 日常の時間管理と通知関連のツール |
| 🔗 Web・コントローラー | Web サイトのショートカットや対応ゲームパッドの状態確認 |

**制限事項：** 各機能はプレビュー版、Windows、ハードウェア、権限、外部 Web サイトや API の対応状況によって利用できない場合があります。FPS、PING、GPU、価格情報は他のソフトと一致するとは限りません。本プレビュー版には **CPU／GPU 温度監視機能はありません**。

## 🖥️ Setup EXE のインストール手順

1. [v6 Release](https://github.com/DavidV20230/vantoryn-desk/releases/tag/preview-v6) の **Assets** から `VantorynDesk-Setup-v6-Windows-x64.exe` をダウンロードします。
2. Setup を実行し、**インストール先のフォルダーを指定**します。表示される進捗はローカルのインストール処理であり、インターネットのダウンロード速度ではありません。
3. インストールが正常に完了すると、アプリが自動起動し、セットアップ画面は自動で閉じる設計です。
4. 次回からは Setup を再実行せず、デスクトップまたはスタートメニューのショートカットから起動してください。
5. 削除する場合は Windows 設定の「インストールされているアプリ」から該当するバージョンを探してください。

## 📦 Portable ZIP の使い方

1. Release の **Assets** にある、Portable と明記された ZIP をダウンロードします。GitHub 自動生成の Source code ZIP は使用しません。
2. エクスプローラーで **「すべて展開」** を選び、例として `D:\Apps\VantorynDesk` など任意のフォルダーに展開します。
3. 展開された `VantorynDesk-Portable-v6` フォルダーを開き、`VantorynDesk.exe` をダブルクリックします。
4. **EXE だけを別の場所に移動しないでください。** `sounds/` などのリソースを相対パスのまま残してください。
5. Portable 版はインストール画面を表示せず、ショートカットの自動作成やアンインストーラー登録も行いません。必要なら手動でショートカットを作成してください。
6. フォルダーを削除する前に必要な設定をバックアップしてください。設定の一部は Windows AppData に保存される場合があります。

## 🔧 よくある質問・トラブル対応

**Q：ZIP 内の EXE が起動しません。** ZIP を完全に展開し、Windows 10／11 x64 かどうか、必要なリソースが揃っているか確認してください。Windows のセキュリティ警告も確認し、ソフトを実行するためにウイルス対策機能を無効にしないでください。

**Q：GitHub の Source code ZIP と内容が違うのはなぜ？** Source code はリポジトリから自動生成されます。別途アップロードする Portable ZIP は Windows の実行ファイルとリソースを含む配布物です。

**Q：毎回 Setup が表示されます。** インストール後は Setup を開かず、アプリのショートカットから起動してください。インストーラーは同一ビルドの状態を確認する場合がありますが、別バージョンでは更新や修復が必要です。

**Q：サイズ変更時にカクついたり、画面が欠けたりします。** 対象ウィジェット、ドラッグした場所、Windows のバージョン、個人情報を隠したスクリーンショットを [Issues](https://github.com/DavidV20230/vantoryn-desk/issues) へお寄せください。

**Q：FPS や価格が表示されません。** ゲーム、ハードウェア、権限、データ提供元が対応していない場合があります。空欄はゼロを意味せず、ハードウェア故障の診断にもなりません。

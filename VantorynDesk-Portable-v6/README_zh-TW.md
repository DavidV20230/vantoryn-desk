# 💜 Vantoryn Desk — 免費 Windows 桌面小工具

Vantoryn Desk 是一套供 Windows 10／11（64 位元）使用的免費桌面小工具。你可以依自己的習慣挑選工具、移動位置、調整大小與收合視窗，將系統資訊、遊戲效能、網路、行情和日常效率功能放在桌面上。

這是**個人使用 AI 大量協助撰寫和修改程式**、透過實際試用持續調整的分享作品；不收費、不要求贊助，也不把它宣稱為專業團隊維護的商業產品。目前版本為 **Public Preview v6（公開預覽版）**。

## 🧩 自訂與桌面配置

- **選擇小工具：** 開啟工具選擇畫面，依工作、遊戲或日常需求選擇要顯示的工具，不必把每一項都放在桌面。
- **自由移動：** 用滑鼠拖動小工具到想要的位置。不同工具可能提供不同的拖曳區域。
- **拉伸尺寸：** 對支援縮放的工具，拖拉邊緣或角落調整大小。v6 已嘗試減少拖曳過程的重繪與裁切，但實際流暢度仍取決於裝置與小工具內容。
- **精簡與收合：** 對支援的工具切換成較小的顯示狀態，遊戲效能小工具也有螢幕邊緣的精簡分頁設計。
- **外觀選擇：** 部分小工具可調整透明度、背景或顯示方式。實際選項以畫面提供者為準。
- **個人內容：** 可依功能自行加入待辦事項、設定專注時間、選擇自選股和市場指數，或新增常用網站入口。
- **語言：** 首次啟動預設英文；在**工具選擇畫面右上角**的下拉選單切換 English／繁體中文／日本語。已選語言會保存在使用者設定中。

## 🖥️ 安裝版使用說明

1. 開啟 [v6 Releases](https://github.com/DavidV20230/vantoryn-desk/releases/tag/preview-v6)，在 **Assets** 下載 `VantorynDesk-Setup-v6-Windows-x64.exe`。
2. 執行 Setup，選擇**實際要安裝的位置**；進度條顯示的是安裝檔案的處理進度，不是網路下載速度。
3. 成功安裝後，程式預期會自動啟動，安裝器自動關閉。
4. 此後從桌面／開始選單的捷徑開啟，不必再次點 Setup。
5. 如需移除，請從 Windows「已安裝的應用程式」尋找對應版本的解除安裝入口。

## 📦 免安裝 Portable ZIP 使用說明

1. 在 Releases 的 **Assets** 下載明確標示為 Portable 的 ZIP；不要下載自動產生的 `Source code (zip)`。
2. 在檔案總管中選擇「全部解壓縮」，建議放在自己選定的資料夾（例如 `D:\Apps\VantorynDesk`）。
3. 打開解壓縮後的 `VantorynDesk-Portable-v6` 資料夾，雙擊 `VantorynDesk.exe`。
4. **不要只把 EXE 單獨拉出來**；請保留 `sounds/` 和其他附件在原相對位置。
5. Portable 不會執行安裝精靈、建立捷徑或 Windows 的解除安裝登錄。需要桌面捷徑可自行右鍵 EXE 建立。
6. 刪除程式資料夾前，先備份想保留的設定；使用者資料可能另外儲存在 Windows AppData。

## 🔧 常見問題與檢查

**Q：點 ZIP 裡的 EXE 沒反應？** 請先完整解壓縮，確認使用 Windows 10／11 x64、未將程式資源分開，並查看 Windows 安全提示。不要為了使用軟體而關閉防毒保護。

**Q：為什麼 Source code ZIP 和 Portable ZIP 不一樣？** `Source code` 是 GitHub 自動將網頁儲存庫內容打包；Portable 才是另外準備、包含 Windows EXE 與程式資源的附件。

**Q：已安裝還看到安裝器？** 平常請點桌面快捷圖示，不要再次執行 Setup。相同安裝包會嘗試檢測既有完整安裝，但不同版本可能需要更新／修復。

**Q：縮放仍會卡頓？** 請附上發生問題的小工具名稱、滑鼠拉伸位置、Windows 版本與遮蔽隱私的畫面，在 [Issues](https://github.com/DavidV20230/vantoryn-desk/issues) 回報。

**Q：行情或 FPS 沒有數值？** 可能是資料來源暫時不可用，或遊戲、硬體、權限不支援。空白不等於零，也不代表硬體故障。
